# Printable reviewers

The learner-approved format for printed or PDF review notes.

## Paper

Long bond portrait (8.5 × 13 in) by default. Use A4 or letter only when asked.

## Layout

1. **Page 1:** a whole-topic map. Each box lists the card codes it covers.
2. **How-to-use page:** a table of the blocks, plus either a formula sheet or a "Don't confuse" table of look-alike ideas.
3. **Blocks:** each opens with a numbered decision path, the questions to ask in order.
4. **Last page:** a quick-recall table. Cover the answers and test yourself.

## Abbreviations

Spell out every abbreviation, or list it in a printed key. A build script should fail if a printed abbreviation is missing from the key. Capitalized emphasis words used by the instructor (NOT, EXCEPT) are fine.

## Theory cards

Written for answering exam questions:

- A plain-words line.
- Three to five "know this" facts.
- An **"If the question says… → Pick…"** table in the instructor's or source's wording.
- A short example.
- One exam trap.
- The source quiz items the card answers.
- A recall question.

For a confusing family of terms, explain them in one box: a tree diagram plus a table using one running example.

For a choice among several look-alike answers, give a **step filter**: numbered questions in order, the clue words that point to each branch, a result grid and one worked "try it" line.

## Practice items

- Tutor-made items in the source's format: four options a–d; stems such as "except", "most likely", "best described as", "which is correct".
- Answers on a page at the back. Spread the keys evenly across a–d.
- Don't reuse items reserved for a pending check.

## Mistakes reviewer

For each missed item:

1. The original question with all four choices. The learner's pick in red, marked "✗ your pick" (no strike-through). The key in green, marked "✓ correct".
2. Why the pick fails.
3. The rule in plain words.
4. A tell-apart table for the confused pair.
5. A one-line memory hook.
6. The related reviewer card.
7. One fresh question (answers on the last page).

Open with grids of the most-missed distinctions.

## Scope and exposure

- Worked examples use tutor-made figures unless labelled as source examples.
- Don't print handout or quiz answers meant to stay as practice, or supplied solution keys.
- Note in the subject progress log that later answers on rules the cards state are supported practice.

## Before-and-after check

When the learner wants one, split the items into two matched sets. Set A before reading: give the score and the topics missed. Set B after reading, then explanations. Record every answer.
